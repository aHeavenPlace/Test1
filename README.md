## 🌟 Descripción

ZENITH es un landing page para un estudio ficticio de diseño web ultra-avanzado, inspirado en la estética minimalista oriental-japonesa. El diseño combina elementos tradicionales japoneses con tecnología moderna, creando una experiencia visual única y elegante.

### ✨ Características

- **Diseño Dark Mode**: Estética oscura elegante con acentos dorados
- **Minimalismo Japonés**: Inspirado en el concepto "ma" (espacio vacío)
- **Tipografía Bilingüe**: Combinación de inglés y japonés vertical
- **Animaciones Suaves**: Transiciones fluidas y efectos de scroll
- **Totalmente Responsive**: Adaptable a todos los dispositivos
- **Código Limpio**: Estructura profesional y mantenible

## 🚀 Instalación y Uso

### Opción 1: Clonar el repositorio

```bash
git clone <repository-url>
cd zenith
```

### Opción 2: Descargar ZIP

Descarga el proyecto como archivo ZIP y descomprímelo en tu directorio local.

### Ejecución Local

Simplemente abre `index.html` en tu navegador web preferido:

```bash
# En macOS
open index.html

# En Linux
xdg-open index.html

# En Windows
start index.html
```

O utiliza un servidor local:

```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (npx)
npx serve
```

Luego visita `http://localhost:8000` en tu navegador.

## 🎨 Personalización

### Colores

Edita las variables CSS en `css/styles.css`:

```css
:root {
    --bg-primary: #0a0a0a;
    --bg-secondary: #111111;
    --text-primary: #ffffff;
    --text-secondary: #a0a0a0;
    --accent-gold: #d4af37;
    --accent-gold-light: #f4cf57;
}
```

### Contenido

Modifica el texto en `index.html` para personalizar:
- Nombre del estudio
- Servicios ofrecidos
- Información del equipo
- Datos de contacto
